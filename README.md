# UI Foundry Radio Button Component Generator

Standalone visual radio-button generator built with Next.js.

This app is a focused radio-group studio for single-choice controls, branded option sets, and styled selection patterns that can be edited visually and exported as code.

## Product summary

This generator is designed for:

- designers building forms, surveys, pricing selectors, and settings panels
- developers who want editable radio-group styling without rebuilding the component by hand
- freelancers and agencies preparing branded choice controls for client interfaces
- buyers who want a standalone radio-button tool consistent with the UI Foundry suite

## What the product includes

- section-based editing controls
- live preview panel
- code view with copy support
- file export support
- searchable preset library
- generated premium preset catalog with filters, paging, and surprise-me apply
- undo and redo controls
- self-contained standalone app structure
- native metadata and description controls for real radio-group authoring

## Editing coverage

The editor currently includes these control areas:

- Presets
- Basics
- Metadata
- Appearance
- States
- Description & Messages
- Typography
- Effects
- Accessibility

These sections cover option setup, native metadata, visual styling, checked and disabled states, description and support messages, label typography, effects, and accessibility metadata.

## Export workflow

The preview and code output follow the same current radio-group state so the exported result matches the visual editor closely.

## Why this product is useful

This is more than a fixed radio control. It is a reusable single-choice component studio for branded form and preference UI.
